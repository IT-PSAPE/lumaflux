# Desktop workspace
Mode: Operate. Photos carry the visual content; controls recede.
Use a neutral charcoal canvas, slightly lighter panels, subtle separators, warm white text and muted gray secondary text. A pink accent identifies selected images and primary actions. System sans-serif typography, 10–12px labels and controls, 24px buttons, 40px top bar, 48px library toolbar, tabular numeric values. Library always shows its resizable left sidebar (220px default) with All photos, Favorites, Exports, imported folders, directory exploration, and bottom import actions. Its editing inspector stays hidden. Edit mode hides file navigation and shows a resizable inspector (280px default). Panel widths persist locally. The inspector separates Adjustments (Light, Color, Details), Composition, and Info. One 36px viewer toolbar groups undo/redo/reset on the left with photo navigation, comparison and zoom. File identity and dimensions are in Info. Composition shows a draggable crop frame automatically, ratio locking, and a straighten slider. Compare places the neutral original beside the edited result. No decorative gradients, marketing cards, or animations. Buttons and fields have clear focus rings. Dialogs remain within window bounds. Viewer controls stay accessible above the canvas; photo editing controls are disabled until a photo is active.
