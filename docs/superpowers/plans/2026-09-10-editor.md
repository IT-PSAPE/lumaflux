# Lumaflux Implementation Plan

User approved autonomous implementation and routine decisions on 2026-09-10.

**Goal:** Deliver the Electron photo workflow and shared local MCP control described in the design.
**Architecture:** A single catalog service serializes edits. Worker rendering serves identical recipes to UI previews and exports. MCP and IPC share commands.
**Tech Stack:** Electron, TypeScript, React, Base UI, Tailwind, Sharp, official MCP SDK.
**Spec:** ../specs/2026-09-10-lumaflux-design.md

## Global constraints
Originals never change. Standard raster formats first; no RAW development. Renderer has no Node access. MCP is opt-in, authenticated, loopback-only. Atomic edits use expected revisions. Preview/export use the same processing pipeline. No further approval checkpoints per user direction.
